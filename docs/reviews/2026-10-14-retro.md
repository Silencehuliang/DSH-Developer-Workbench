## 1. 机械性违规被写成了规则，而不是检查（已在本轮做掉）

**这是最严重的一条，而且它真的发生了。**

实现期间我犯了两个**机械性**错误：

- `client.js` 里写死 `color: '#fff'` —— 违反了 `AGENTS.md` 里「前端颜色一律用主题 token」
- `ProjectRow` 是 `div + onClick` —— 鼠标专属，键盘到不了

两次都**没有**被拦住，因为我只是把它们**写成了规则**。`retro` 的标准说法是：机械性违规
「gets a deterministic check, full stop」，并且要「default to building the check over writing the rule」。

`#fff` 在评审时被两条轴同时抓到；`div + onClick` 更隐蔽 —— 它在文本断言里长得和 `button` 一模一样。

**已做：**

- 新增 `styles: no component renders a hardcoded colour`：遍历**每个渲染树的 inline style**（旧断言只扫样式表，这正是 `#fff` 逃逸的原因）
- 新增 `accessibility: no clickable element is unreachable from the keyboard`：任何带 `onClick` 的宿主元素必须在 `button` / `a` / `input` / `select` / `textarea` / `summary` / `option` 里
- 两条都配了「审计确实走到了东西」的守卫，防止空跑通过

**为什么值得单列：** 这两条现在挡住的是**一整类**错误，不是两个实例。

## 2. 仓库没有任何守卫（已在本轮做掉）

`retro` 说得很直白：**没有守卫的仓库本身就是一条发现** —— 不是中性默认值。

这个仓库当时确实什么都没有：没有 CI、没有 pre-commit、连一个 check 命令都没有。所以
「每改必跑」实际上依赖**我记得跑**，而不是结构在跑。上面两个机械性缺陷能活下来，正是因为这个。

**已做：**

- 根 `package.json`：`npm run check`（密封，不需要服务）/ `verify` / `acceptance`
- `.githooks/pre-commit`：每次提交跑 `--client-only`（不需要服务，因此可以在提交时跑）
- 激活：`git config core.hooksPath .githooks`

**诚实说明：** `node` 不在 PATH 时钩子会**打印警告并放行**，而不是假装检查过。这个跳过是可见的，但它确实是个洞。

## 3. `AGENTS.md` 承载了规则，但它是每轮都加载的（已在本轮做掉）

`retro` 的参考部分对这两个文件的分工说得非常明确：

> `CLAUDE.md`/`AGENTS.md`：**sparingly，通常只用于 navigation pointers**。
> `CODING_STANDARDS.md`：**在评审时读，而不是实现时**。

我原来的 `AGENTS.md` 是 60 多行规则 + 已知坑，**每一轮都进上下文**；而规则本该在评审阶段读
（评审上下文压力最小，实现上下文压力最大 —— 这正是分工的理由）。

**已做：**

- `CODING_STANDARDS.md`：规则按「机械性（已变成检查）/ 判断题」分栏。**每条机械规则都写上对应检查的名字**，评审时直接跳过那些
- `AGENTS.md` 瘦成三条导航指针 + 一条硬约束 + 一条检查命令

**顺带一个副产品：** 分栏时发现有一条规则我在 `CODING_STANDARDS.md` 里写了「有检查」，但那条检查**当时并不存在**（归属文件）。已经补上实现与断言 —— 文档里声称的检查必须真的存在。

## 4. 插槽契约被反复查询，而不是记录成指针（已在本轮做掉）

**工具经济性。** 我为了同一个问题查询了 `Slots.listSubTree` 大约 **7 次**，每次返回
2–4 KB 的完整目录（ownerProps、standardProps、catalog 描述），只为读里面两三行。

`writing-for-agents` 里有现成的解法：**disclosed reference + 一条指针**。

**已做：** `docs/slots.md` —— 我们占用的五个插槽、它们的 scope、order、我们注册的 id、
以及宿主传给它们的 props；外加用到的宿主服务与客户端服务。`AGENTS.md` 里指过去，
并明说「**不要再去查询插槽契约**」。

这条路以后每次涉及插槽的工作都能省掉若干次大查询。
